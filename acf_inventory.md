# Dragon Magazine Compendium - alternative class features and substitution levels: verified inventory

Status per entry: **repo** = already in the repository (book) - not repeated; **build** = to build in the compendium; **done** = built and verified.
Repository mechanisms: ACFs are CATEGORY:ACF abilities typed with the base class's guard (e.g. ACF.PaladinTurnUndead), chosen in
"Alternate Class Feature"; the base class's feature carries !PREABILITY:1,CATEGORY=ACF,TYPE.<guard>. Substitution levels are
SUBSTITUTIONCLASS / SUBSTITUTIONLEVEL blocks under CLASS:<base>.MOD (e.g. Champions of Valor, Races of the Dragon).
